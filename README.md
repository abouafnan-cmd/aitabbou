# منصة تسجيل حضور وغياب الطلبة

لتجربة الواجهة ومزايا التصدير (PDF / CSV / TXT) محليًا:

1. ثبّت المتطلبات المدمجة (لا حاجة لحزم خارجية، المشروع ثابت بالكامل).
2. من داخل مجلد المشروع شغّل خادمًا بسيطًا:
   - Python 3: `python -m http.server 8000`
   - أو Node.js: `npx serve -l 8000` (إن توفّر)
3. افتح المتصفح على العنوان: <http://localhost:8000>.
4. إن احتجت لفتح الملف مباشرةً يمكن استخدام `index.html`، لكن خادم محلي يضمن تحميل الخطوط والملفات المرافقة بشكل صحيح.

> ملاحظة: كل شيء داخل مجلدات `css/` و`js/`، لذا تأكد من تشغيل الخادم من جذر المشروع حتى تُحمَّل الموارد.
